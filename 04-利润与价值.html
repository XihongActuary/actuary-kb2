见山不是山（三）：利润与新业务价值

不推销，只讲逻辑。花10分钟读完，比你自己研究一个月都有用。

前三篇我们拆解了保费、现金价值和红利。但公司卖这张保单到底赚不赚钱？股东能分到多少钱？这就引出了新业务价值（NBV）——评价新保单盈利性的最核心指标。

这一篇，我们按照现金流 → 相应负债 → 税后利润 → 要求资本 → 可分配盈余 → NBV的链条，逐层拆解，并且告诉你：为什么剩余边际（DPL）可以“抵扣”要求资本，从而让好产品更省资本。

🧭 一句话核心
新业务价值（NBV）= 未来可分配盈余的现值。
可分配盈余 = 税后利润 − 要求资本变动 + 要求资本的投资收益。
剩余边际（DPL）可以直接抵扣要求资本，高价值产品因此资本占用更低。

📌 一、全景流程图：从现金流到NBV

【保单现金流预测】    ↓ 【相应负债 Liabt = RESt + DPLt】    ↓ 【税后利润 Profitt = (现金流 + 投资收益 − ΔLiabt) × (1−TaxRate)】    ↓ 【要求资本 RCt ≈ max( MCt − (DPLt−DTLt), 0 )】    ↓ 【可分配盈余 DEt = Profitt − ΔRCt + RCt-1 × InvRate × (1−TaxRate)】    ↓ 【新业务价值 NBV = Σt>0 DEt / (1+RDR)t】

📌 二、从现金流到税后利润

税后利润不是简单的“保费减赔付”，还要考虑相应负债的变动（相当于“要多存钱”或“可释放钱”）。公式如下：

Profitt = ( GPt − Expt − Claimt − Lapset − Divt + Invt − ΔLiabt ) × (1 − TaxRate)

其中：

  • GPt：保费收入
  • Expt、Claimt、Lapset、Divt：费用、赔付、退保、红利支出
  • Invt = (Liabt-1 + GPt − Expt) × InvRate（投资收益）
  • ΔLiabt = Liabt − Liabt-1：相应负债提转差（负债增加减少利润）
📢 说人话：赚到的利润 = 收的钱 − 花的钱 − 当年要多存起来的钱（负债增加）。如果负债减少，相当于把以前存的钱拿出来，利润就会增加。

📌 三、相应负债的构成：寿险合同负债（RES） + 剩余边际（DPL）

内含价值评估中的“相应负债”不是会计准备金，而是：

Liabt = RESt + DPLt
  • RESt（寿险合同负债）：按偿付能力监管要求计提，包含最优估计、风险边际、TVOG。
  • DPLt（剩余边际）：签单时首日利得的“蓄水池”，后续逐年摊销。它相当于未来利润的提前锁定，也是可以抵扣要求资本的核心要素。
💡 剩余边际是“好产品”的标记。长期保障型产品剩余边际厚，能抵扣更多要求资本；低价值理财型产品剩余边际薄，资本消耗高。

📌 四、要求资本（RC）与剩余边际的“抵扣效应”

要求资本是监管要求必须持有的最低资本，以防公司倒闭。简化公式（忽略现金价值影响）：

RCt ≈ max( MCt − (DPLt − DTLt), 0 )

其中：

  • MCt：最低资本（保险风险+市场风险+信用风险）
  • DPLt：剩余边际
  • DTLt = DPLt × 10% （递延所得税负债）

核心含义：剩余边际可以“抵扣”要求资本。剩余边际越厚，公司实际需要额外持有的资本越少。这就是为什么高价值产品（重疾险、终身寿险）资本占用低，而低价值产品（短期理财险）资本占用高。

📢 说人话：监管要求公司必须留一笔“备用金”。但如果你这份保单未来能赚很多钱（剩余边际厚），监管就允许你少留一点备用金。所以好产品更省资本。

📌 五、要求资本的变动 ΔRCt

每年的要求资本会变化。要求资本增加，意味着当年要多从利润里“锁住”一部分钱；减少则意味着释放以前锁住的钱。

ΔRCt = RCt − RCt-1

当 ΔRCt > 0，当年可分配盈余会减少；当 ΔRCt < 0，可分配盈余会增加。

📌 六、可分配盈余（DE）与新业务价值（NBV）

可分配盈余是股东真正能分到手的现金：

DEt = Profitt − ΔRCt + RCt-1 × InvRate × (1 − TaxRate)

然后，把未来各年的可分配盈余用风险贴现率（RDR）折现求和，就是新业务价值（NBV）：

NBV = Σt>0 DEt / (1+RDR)t

NBV直接反映一张新保单能为股东创造多少价值。正数的NBV才值得卖，负的NBV卖得越多亏得越多。

💡 为什么NBV比会计利润更重要？会计利润受准备金释放节奏影响，可能前期亏、后期赚，而NBV是对全生命周期的一次性现值评估，能真实反映新业务的长期盈利能力。
