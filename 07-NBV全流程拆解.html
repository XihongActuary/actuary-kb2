新业务价值（NBV）全流程拆解

不推销，只讲逻辑。花10分钟读完，比你自己研究一个月都有用。本文整合公司《产品开发手册》与最新精算标准，以“可分配盈余 = 税后利润 − 要求资本变动 + 要求资本投资收益”为主线，逐层拆解新业务价值（NBV）。
🧭 一句话核心
新业务价值（NBV / NBEV） = 未来各年度“可分配盈余”的现值。
可分配盈余 = 税后利润 − 要求资本变动 + 要求资本的投资收益。
剩余边际（DPL）可以直接抵扣要求资本，高价值产品更省资本。

📌 一、什么是新业务价值（NBV / NBEV）？

新业务价值是当年新销售保单在未来创造的、可分配给股东的税后利润的现值。它直接回答：“今年卖的这张保单，到底给股东创造了多少价值？”

它不是会计利润，因为会计利润受费用前置、准备金释放节奏影响，无法反映长期股东回报。NBV扣除了要求资本的机会成本，是评估新单盈利性的最核心指标。

📢 说人话：NBV就像你种了一棵果树，未来每年结的果子，扣掉肥料钱、人工费后，折现到今天值多少钱。果子还没长出来，但已经可以估算它的价值。

📌 二、从现金流到新业务价值的全景流程图

【保单现金流预测】    ↓ 【计算相应负债 Liabt = RESt + DPLt】    ↓ 【计算税后利润】Profitt    ↓ 【计算要求资本 RCt 及其变动 ΔRCt】    ↓ 【计算可分配盈余】DEt = Profitt − ΔRCt + InvtRC    ↓ 【折现求和】NBV = Σt>0 [ DEt / (1+RDR)t ]

📌 三、第一步：现金流预测

每个保单年度 t 的净现金流为：

净现金流 = GPt − Expt − Claimt − Lapset − Divt
  • GPt：保费收入
  • Expt：费用支出（佣金、维持费、监管费等）
  • Claimt：理赔支出（身故、重疾、生存金、满期金）
  • Lapset：退保金
  • Divt：红利支出
💡 现金流是“实际发生”的金额，不是会计确认的保费收入。

📌 四、第二步：相应负债（Liabt）的构成

内含价值评估中的“相应负债” = 寿险合同负债 RESt + 剩余边际 DPLt。

4.1 寿险合同负债 RESt

RESt = PVCFt + TVOGt + RMt

其中：

  • PVCFt：负债现金流现值
  • TVOGt：选择权及保证利益的时间价值（利率保证成本）
  • RMt：风险边际，采用分位点法：
    RMt = MCt保险风险 × [Φ⁻¹(85%) / Φ⁻¹(99.5%)]

4.2 剩余边际 DPLt

剩余边际是为了不确认首日利得而设立的负债。签单时若 RES0 < 0，则 DPL0 = −RES0，并在整个保险期间按有效保单件数摊销：

DPLt = PACt × k，其中 k = DPL0 / PAC0，
PACt = Σn=0bt IFt+n × Discn
说人话：剩余边际就是“未来利润的蓄水池”，签单时先把利润存进去，然后随着保单服务逐年释放到利润表中。

📌 五、第三步：税后利润 Profitt 的计算

Profitt = ( GPt − Expt − Claimt − Lapset − Divt + Invt − ΔLiabt ) × (1 − TaxRate)

其中：

  • 投资收益 Invt = (Liabt-1 + GPt − Expt) × InvRate
  • 相应负债提转差 ΔLiabt = Liabt − Liabt-1
关键点：负债增加（ΔLiabt > 0）会扣减利润，因为要多存钱；负债减少会增加利润。

📌 六、第四步：要求资本 RCt 及变动

6.1 要求资本（RC）的精确公式

RCt = max{ MCt + max[ CVt − (RESt + MCt), 0 ] − (DPLt − DTLt), 0 }

其中：

  • MCt：最低资本（偿二代二期下保险风险、市场风险、信用风险之和）
  • CVt：现金价值
  • RESt：寿险合同负债
  • DPLt：剩余边际
  • DTLt：递延所得税负债（通常 DTLt = DPLt × 10%）

6.2 精算含义：剩余边际的“抵扣”效应

忽略中间项（实务中该值几乎为0），公式简化为：

RCt ≈ max( MCt − (DPLt − DTLt), 0 )

即：要求资本 = 最低资本 − 剩余边际（税后价值）。剩余边际越厚的产品，要求资本越低。这就是为什么长期保障型产品（剩余边际高）资本占用少，而低价值理财型产品反而更“吃资本”。

6.3 要求资本变动

ΔRCt = RCt − RCt-1
  • 若 ΔRCt > 0：需额外锁住资本，减少可分配盈余。
  • 若 ΔRCt < 0：释放资本，增加可分配盈余。

📌 七、第五步：可分配盈余 DEt 的计算

DEt = Profitt − ΔRCt + RCt-1 × InvRate × (1 − TaxRate)
可分配盈余 = 税后利润 − 当年新增锁死的资本 + 锁死资本产生的税后投资收益。这才是股东真正能拿到手的现金流。

📌 八、第六步：新业务价值的最终计算

NBV = Σt=1T DEt / (1 + RDR)t

其中 RDR 是风险贴现率（Risk Discount Rate），通常取11% – 12.5%，反映了股东对长期不确定性的回报要求。

📌 十二、总结：新业务价值全链条速记

🔁 六步闭环
1️⃣ 现金流 → 保费、赔付、费用、红利
2️⃣ 相应负债 Liabt = RESt + DPLt（含风险边际、TVOG）
3️⃣ 税后利润 Profitt = 现金流 + 投资收益 − 负债增加
4️⃣ 要求资本 RCt = max( MCt − (DPLt−DTLt), 0 )
5️⃣ 可分配盈余 DEt = Profitt − ΔRCt + RCt-1 × InvRate × (1−TaxRate)
6️⃣ 新业务价值 NBV = Σt=1T DEt / (1+RDR)t
📢 最终大白话：新业务价值就是剔除了“被监管锁住的资本”之后，股东真正能拿到手的未来利润的贴现值。它比会计利润更真实地反映了新保单对股东的价值贡献。
